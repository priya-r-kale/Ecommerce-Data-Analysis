**# E-Commerce Data Analysis Project**



**## Project Overview**

**This project focuses on analyzing e-commerce order data using Python. It includes data loading, data cleaning, exploratory data analysis, and data visualization to understand product revenue, marketing channels, and order trends.**



**## Dataset Information**

**- \*\*Dataset Name:\*\* orders-data.xlsx**

**- \*\*Total Rows:\*\* 21,864**

**- \*\*Total Columns:\*\* 11**



**### Dataset Columns**

**1. USER\_ID**

**2. ORDER\_ID**

**3. PURCHASE\_TS**

**4. SHIP\_TS**

**5. PRODUCT\_NAME**

**6. PRODUCT\_ID**

**7. USD\_PRICE**

**8. PURCHASE\_PLATFORM**

**9. MARKETING\_CHANNEL**

**10. ACCOUNT\_CREATION\_METHOD**

**11. COUNTRY\_CODE**



**## Technologies Used**

**- Python**

**- Jupyter Notebook**

**- Pandas**

**- NumPy**

**- Matplotlib**

**- Seaborn**



**## Project Workflow**



**1. Import required Python libraries.**

**2. Load the Excel dataset using Pandas.**

**3. Explore the dataset using `head()`, `shape`, `info()`, and `describe()`.**

**4. Check and handle missing values.**

**5. Fill missing price values using the mean.**

**6. Fill missing categorical values with `Unknown`.**

**7. Identify and remove duplicate records.**

**8. Convert purchase and shipping dates into datetime format.**

**9. Perform data analysis and visualization.**



**## Data Analysis and Visualizations**



**The project includes the following analysis:**



**- Product-wise Revenue Analysis**

**- Orders by Marketing Channels**

**- Weekly Orders Shipped (2019–2021)**

**- Yearly Order Volume Trends**

**- Orders Shipped by Year**
